# Event 时间与元数据输入反馈

沿用已批准的主界面/画布编辑流程，修复共享 InlineEventEditor 中可确认的无反馈路径：Start/End 解析失败或逆序时，“应用”此前直接返回；Layer 非整数时，仍可提交 Actor/Comment 并静默沿用旧 Layer。ViewModel 还会把超出 -999～999 的 Layer 静默夹到边界。

时间输入使用原 SubTime.fromEditable 语义，支持 ASS 时间及非负毫秒数；错误定位到对应字段，End 早于 Start 单独提示。无效时禁用应用，回调再次校验；等时和0维持原行为。本轮不收紧底层 ASS 时间解析语法。

Layer 提示非整数或超出本编辑器现有 -999～999 支持范围，并禁用元数据应用，避免旧值回退和无提示夹取。该范围来自当前 ViewModel，不是宣称 ASS 标准只允许该范围。有效负数仍可提交。取消、文档写入和 Undo 接口不变。

新增5项领域测试覆盖既有两种输入格式、错误字段、空/负/溢出时间、逆序及等时。初次命令因测试函数声明拼写错误失败，不计为有效RED；纠正后仅因缺失实现失败，随后完整领域源码与测试编译运行253/253。使用 Kotlin 反射 harness 和原始资源，不能替代 Android/Gradle。

新增真实 Activity 双 Host 回归，检查错误文本、禁用状态、无效输入不改文档、修正时间/负 Layer 后可应用并一次 Undo。该测试及 Compose 集成未在本地执行，无设备视觉验收结论。源码复核补出 ViewModel Layer 夹取边界，UI同步显示当前编辑范围。
