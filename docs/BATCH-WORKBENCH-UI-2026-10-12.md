# 批量工作台 UI 组织改进

基线：远端 c89d34475a4f5c08fda8f37f91520d0d895eb351，本地183a0680同tree。用户要求继续改进UI，本单元沿用已批准的字幕效率、明确作用范围和预览提交流程，保留主界面与画布。

## 实际界面变化

- 原来组合规则和结构化搜索替换连续堆在同一条长表单中。现在用两个明确工作页分别承载，各自参数与结果可垂直滚动。
- 字幕范围用2×2卡片呈现四种选项；不再横向隐藏“整个文档”，同时保持范围数与共享列表筛选的说明。搜索替换字段目标也改2×2呈现。
- 每个工作页的预检与应用位于有限窗格底部，离开表单滚动区域。操作区显示范围数、待预检/零变更/变更条数或错误摘要；错误全文与变更列表仍在内容区。
- 切工作页是presentation变化，保留当前参数和预检；实际参数改变仍使两条管线的预检失效。不会自动提交正文或改变ASS Undo边界。
- 主编辑器根布局统一消费IME底部空间，主界面与画布共用避让后的视口；每个节点不重复应用键盘padding。
- 产品文案改用“筛选条件、修改内容、变更预览”，保留Style、Actor、Raw ASS等必要技术术语。
