# ASS 主 UI、字幕编辑效率与无限画布改版设计

状态：用户已批准修订方向 / 实施中；本文件不声明产品功能已实现。
日期：2026-10-11（Asia/Shanghai）
基线：`redesign/infinite-canvas-workbench-v2@69ad5c076c8695fae15c59b01cd391a647bb8652`，草稿 PR #138。

## 1. 目标与已确认意图

用户要求继续推进 ASS 项目、加入新内容、重做主 UI、改进无限画布 UI，并选择新增能力优先为“字幕编辑效率”。改版服务于实际字幕制作：看参考画面，找到事件，修改正文或参数，必要时批量处理，确认效果并保存。

设计假设：手机仍是首要触控场景，同时保留平板、多窗口、外接键盘；保留 FIXED 与 SPATIAL_EXPERIMENTAL 两种呈现。不是另建第三种实验布局。颜色与装饰不是这次主要成功指标。

成功标准：常用任务入口稳定；筛选、焦点、选择、写入范围可区分；减少重复工具条占用；切换布局、筛选、编辑工具及 IME 不丢未应用草稿；画布组织保持原节点身份、绑定和世界几何。

## 2. 当前事实与验证边界

- `FixedWorkspace` 有两行横向滚动的分组与工具芯片，另有全局顶栏和紧凑布局分页。
- `SearchStrip` 当前只提供正文 / Actor / Style 合并字符串查询；`EditorState.filteredEvents` 实现该 OR 筛选。
- `EventWorkspace` 已提供筛选计数、上一条 / 下一条筛选结果以及基于筛选列表的区间选择，不重新开发这些能力。
- `SemanticSearchReplacePane` 已有正文、Raw ASS、Style、Actor 替换及预览，但只展示前五条命中摘要，缺少直达结果与清晰的文档/选中/筛选结果作用域衔接。
- 画布分支已有语义缩放、原生密度聚焦编辑、视频参考分区、时间轴、侧书签、鸟瞰搜索、视口历史、方向提示、对象绑定与工具生命周期。
- 最新基线 Android CI `38117186072` 与 Fontconfig `38117186058` success；Emulator `38117186042` failure，失败步骤为 editor regression suite。日志读取失败，具体断言和根因未知，不能把 failure 归因于任一拟议 UI 改动。
- 本环境尚无本轮 Android 编译、截图验收或真实设备结果。旧账本不能当作当前完成率。

## 3. 方案选择

推荐“共享任务入口 + 两种承载”：主界面与画布共用项目状态、字幕筛选和当前对象上下文，保留不同空间呈现。这样既改善主 UI，又不复制编辑状态。

备选一是仅压缩现有工具条，改动较小，但不能解决搜索结果到编辑和批量作用域的断裂。备选二是彻底替换为统一全屏画布，改动与迁移风险更高，也会使只想顺序编辑字幕的人承担空间管理成本。用户于 2026-10-11 批准修订推荐方案：统一工作区核心，保留多 UI。不得以统一引擎为由删除主界面或强制全部任务空间化。正文草稿必须由工程会话持有，不再归属于主界面或画布的承载槽；同一工具实例在不同 Host 中读取同一草稿，独立实例的草稿隔离。

## 4. 主 UI 信息架构

全局顶栏只负责项目名称/未保存状态、保存、主界面/画布切换和文件/全局命令。局部任务栏负责“字幕、排版、时间、更多工具”，每个入口有文字。工具目录仍能访问完整专业能力，不删除旧工具。

主工作区按实际可用宽高重排：

| 场景 | 呈现 |
| --- | --- |
| 手机窄窗口 | 视频参考区 + 字幕列表或编辑器；列表/编辑切换固定可达，当前对象上下文紧邻编辑内容 |
| 中宽窗口 | 字幕导航与编辑区并排；视频参考可折叠 |
| 平板宽窗口 | 字幕导航、真实视频预览、编辑器三栏 |
| IME 或短窗口 | 减少参考画面占用；保留编辑正文、应用/取消、列表返回入口，不重新生成编辑实例 |

“更多工具”打开有分组与搜索的目录，选择后替换局部编辑任务，不再要求连续横向滚动两行工具芯片。保留现有预览密度入口，但用清楚的状态文字表达“显示/紧凑/隐藏”。未载入字幕时显示真实打开/新建动作；未载入视频不阻断 ASS 编辑。

当前字幕上下文显示序号、时间、Style、Actor、已选数量；只有在相关工具支持时展示绑定和明确写入目标。只读绑定不得被误写为批量作用域。单条编辑常用操作为应用、上一条/下一条，不能通过导航默默提交草稿。

## 5. 新增能力：统一筛选与结果操作

引入工程会话所有的 `SubtitleFilterState`，成为两种 Host 共用的列表筛选来源。快速入口提供普通文本，默认同时匹配可见正文/Actor/Style；展开后可单独指定正文、Actor、Style、Dialogue/Comment。默认文字按字面量匹配，正则和 Raw ASS 保留在高级搜索工具。

空筛选显示全部事件；组合条件为 AND，快速文本内部三字段匹配保持 OR；“仅已选”与其他条件取交集。所有结果沿用文档顺序、稳定 Event ID，不按过滤后的序号写入。无结果时显示清空条件入口，不自动改 Focus。

结果栏显示“匹配 M / 全部 N、已选 S”，支持上一/下一命中、“选择全部结果”和“定位当前字幕”。选择全部结果明确替换当前选择，并在点击前标明数量；导航不改选择。当前焦点被过滤掉时显示“当前字幕不在结果中”，定位操作提示清除筛选，不能暗中扩大结果集。

筛选状态在 Activity 重建中恢复；切换工程清空，暂不扩展 `.asswb` wire format。筛选、选择及导航均不产生文档 Undo、dirty 或 recovery 写入。

## 6. 批量替换衔接

复用 `AssSearchReplace`，不另写 ASS parser。批量操作明确选择“全部文档 / 当前筛选结果 / 当前选择”；后两项取快照 Event ID，空集合时禁止应用。默认沿用工具原有全量行为，但显式标示“全部文档”，不得因列表有筛选而假装限制范围。

预览分开显示命中数量与实际修改数量，并提供可点击、可滚动的变更结果及修改前/后文本。点击结果仅定位对应事件；应用以一个 Undo 事务提交。替换草稿、目标 IDs、工程会话和文档基线变化后预览失效，用户须重新预览；不得把旧预览覆盖新文档。正文替换遵守现有 token 边界保护，不能保证跨 override block 的文字匹配都可替换；这一边界在预览中说明。Raw ASS 操作始终明确标注。

## 7. 无限画布 UI

画布继续拥有世界坐标和相机，字幕编辑流程作为既有 ToolInstance 的真实内容进入画布。

- 在聚焦编辑区复用主 UI 的当前字幕上下文、筛选结果定位和批量范围入口，保持原工具 ID 和 Binding。
- 整理画布常驻控件：固定“返回画布、工具、鸟瞰”；把整理、透明度、绑定、关闭等放在相关工具菜单。历史、缩放、时间轴属于画布导航，不挤入正文编辑栏。
- 底部只保留一组工具实例切换入口；左抽屉作为显式展开的完整目录，侧书签保留用户选择的常用实例。用明确状态区分活动、隐藏、书签及失效绑定。
- 鸟瞰继续负责空间寻找，不与“字幕搜索”混用；名称搜索只能过滤 ToolInstance，不改变字幕筛选。
- 总览卡展示标题与绑定摘要，近景原生控件不随相机缩小；普通编辑器不能为了节省绘制而被无条件销毁。
- 筛选和工具切换不能自动整理世界几何。显式整理继续保留锁定节点、隐藏状态与 z-order；布局 Undo 与文档 Undo 不合并。

本轮不增加命名区域、任意参数组合、独立时钟、真实玻璃模糊或任意双写编辑器。它们是独立后续任务，不能借本次重做 UI 默默扩张范围。
