# 空间工作区：位置编辑接入与工具外观设计

日期：2026-10-04。状态：待审阅设计，未实施。

## 目标与依据

保留 ASS Workbench 的位置、缩放、倾斜、旋转转杆、滑块与实时数值反馈，把它们接入可自由组织的空间工作区。第一条真实接入链路为位置编辑。视频保持自身纵横比；工具的初始排列可改变，不规定固定分栏。用户的新反馈是现有窗口 UI 过时且粗糙；以下视觉选择是待验证设计，不是已经证明的审美结论。

依据：2026-10-01 替代版 UI 宪法中的空间分离、手势捕获、固定杆、参数投影、临时预览与提交契约。当前核对的是报告与浏览器原型源码，未核对 Android 最新主干。

## 现状与交付边界

MagicPath 项目 457162568105070592，组件 457166859171663872，查询所得 revision 457176669321588736。原型已有空间组织能力，参数仍为交互夹具；媒体为绘制示意，没有 libass、真实视频或文档事务。不能把浏览器示意验收当成 Android 参数接入验收。

浏览器原型负责验证工具视觉、可操作的转杆/滑块/数值同步及独立编辑历史。Android 接入负责复用原有参数解析、InteractionOverlayRegistry、预览与正式提交路径；具体接口必须先核对源码再确定。

## 视觉设计

采用内容主导的工具表面。降低标题栏高度与对比度，取消逐窗 A/B/C/D 字母装饰；身份改为简短工具名与目标摘要。保留至少 44 dp 的明确拖动区域和操作触摸范围，视觉抓手可以较小。

窗口常驻只保留工具身份、必要绑定信息与更多操作入口。隐藏、成组、固定、最大化等放入上下文操作；不在每个窗口排列完整管理按钮。触控下这些操作可见且一次调用，不依赖 hover。

视频优先显示内容，保持媒体比例，以少量边缘控件提供观察缩放。参数表面以数值、单位、滑轨组织视觉层次；颜色只标记选中、活动模式或异常。弱边框和柔和阴影用于区分重叠对象；不以大面积模糊、玻璃渐变或发光描边代替信息层次。

拖动时就近显示参数值、变化量、单位、粗/精调状态。反馈位置避开触指与字幕，不随参数细微变化跳位。未选中的工具仍可辨识、移动和召回。

## 状态与参数接口

Workspace 持有相机、工具几何、层级、可见性与布局历史；Preview 持有局部观察变换；Document 持有字幕、样式与文档历史。观察或工具布局变化不得改写 ASS。

一个参数描述契约提供目标身份、参数名、单位、读取来源、写入层、范围、重置语义与预览/提交能力。转杆、滑块、数值输入观察同一编辑状态，不能各自复制一份正式值。工具可跟随选择或固定对象，屏幕固定不改变对象绑定。

位置输入的单位为 ASS Script Space，不能把工作区像素当作 PlayRes 单位。转杆手势开始时捕获目标、文档基线、写入层、模式及输入映射。拖动中参数进入临时预览；结束时提交一次；取消时清理预览并恢复基线。目标删除、工程切换、生命周期取消不得提交残留手势。

同一参数的第二入口在活动手势期间不得成为第二写入者；可同步展示或明确等待当前手势结束。开始拖动后改变选择不能重定向写入。

数值即时反馈与异步渲染结果分别标记。渲染请求关联文档 revision、预览序号和媒体时刻，迟到结果不得覆盖较新结果。动态标签的编辑值与当前时刻求值结果明确区分。

## 坐标与手势

ASS 锚点经过视频实际输出矩形、预览局部变换与工作区投影映射到屏幕；须考虑留黑区域。绘制与命中使用同一映射，反向位置输入使用逆映射。显示缩放与字幕缩放独立。

字幕锚点跟随视频，转杆长度、把手及实时提示使用可触的屏幕尺寸。字幕位置直接拖动遵循触点映射；代理转杆的控制—显示增益单独按参数定义。开始手势后不让工作区相机同时变化，避免映射中途改变。保留明确 POSITION/SCALE/SHEAR/ROTATION 模式与“仅转杆”。

内容区手势由具体控件捕获；工具抓手移动工具；空白区操作工作区。低缩放时转为工具摘要，不显示无法点击的小滑块；进入编辑后恢复可读尺寸，不静默改参数或对象绑定。

## 第一轮验收

1. 选字幕，打开位置工具，拖转杆；坐标与滑块同步，真实 libass 预览追随。松手一次提交，Undo 一次恢复。
2. 调整视频观察缩放、移动视频表面或位置工具、缩放工作区，正式位置数值不变，锚点仍正确映射。
3. 同一位置用转杆、滑块、数值输入依次编辑，三个入口没有值分叉；取消恢复基线。
4. 拖动中换选、目标删除、工程切换、pointer cancel 均不误写。文档 Undo 不先撤销相机或工具移动。
5. 横屏平板下控件可触、数值可读，工具重叠后能找回；软键盘出现不遮住正在编辑的关键反馈。
6. 浏览器演示单独标明模拟字幕与模拟预览。Android 渲染和生命周期测试有独立证据后才宣布真实接入通过。

第一轮通过后再接缩放、错切与各轴旋转；不把四类参数的范围、单位与增益套用同一个常数。
